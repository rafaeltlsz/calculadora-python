# Calculadora em Python

Projeto desenvolvido para o trabalho avaliativo de Design Profissional, aplicando na prática os conceitos aprendidos na trilha GitHub Foundations (Microsoft Learn).

## Sobre o projeto

Uma calculadora simples via terminal, feita em Python, que realiza as quatro operações básicas: soma, subtração, multiplicação e divisão. Inclui tratamento de erro para divisão por zero.

## Como executar

1. Certifique-se de ter o Python instalado.
2. No terminal, dentro da pasta do projeto, rode:
3. Escolha a operação desejada no menu e digite os dois números.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento de erro para divisão por zero)
